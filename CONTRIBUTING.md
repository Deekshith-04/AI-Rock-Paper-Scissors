# Contributing to AI Rock Paper Scissors

Thank you for your interest in contributing to this project.

## How to Contribute

You can contribute by improving different parts of the project, including:

- Gesture recognition accuracy
- Dataset quality
- Game features
- User interface
- Documentation
- Testing
- Performance improvements

## Getting Started

1. Fork the repository.
2. Clone your fork locally.
3. Create a new branch for your changes.
4. Make the required changes.
5. Test the changes.
6. Commit your work with a clear commit message.
7. Push the branch to GitHub.
8. Create a pull request.

## Code Guidelines

When contributing code:

- Keep the code clean and readable.
- Use meaningful variable and function names.
- Avoid unnecessary duplication.
- Test changes before submitting them.
- Keep related functionality organized in appropriate files.

## Documentation

If you add a new feature or make significant changes, update the relevant documentation when necessary.

Documentation helps future contributors understand how the project works.

## Reporting Issues

When reporting an issue, include:

- A clear description of the problem
- Steps to reproduce the issue
- Expected behavior
- Actual behavior
- Screenshots or error messages when available

## Feature Suggestions

Feature suggestions are welcome.

Possible areas for future development include:

- Improved gesture recognition
- Additional hand gestures
- Multiplayer gameplay
- Enhanced game statistics
- Improved user interface
- Public deployment

## Pull Requests

Before submitting a pull request:

- Ensure the application works correctly.
- Test the changes.
- Keep the pull request focused on a specific improvement.
- Provide a clear description of the changes.

## Thank You

Every contribution, whether it is code, documentation, testing, or feedback, helps improve the project.
