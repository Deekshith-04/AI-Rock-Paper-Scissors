# Changelog

All notable changes and improvements to the AI Rock Paper Scissors project are documented in this file.

## Version 1.0.0

### Initial Release

- Created the AI Rock Paper Scissors project.
- Added webcam-based hand gesture detection.
- Added Rock, Paper, and Scissors gesture recognition.
- Created a custom gesture dataset.
- Trained a machine learning classification model.
- Integrated the prediction model with the game engine.
- Added computer move generation.
- Implemented Win, Lose, and Draw logic.
- Added score tracking and statistics.
- Integrated the backend with the frontend.
