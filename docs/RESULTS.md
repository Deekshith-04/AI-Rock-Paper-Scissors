# Project Results

## Overview

The AI Rock Paper Scissors project was successfully developed as a real-time gesture-based game.

The application combines computer vision, hand landmark detection, machine learning, and game logic to allow users to play Rock Paper Scissors using real hand gestures.

## Gesture Recognition Results

The gesture recognition system supports:

- Rock
- Paper
- Scissors

The trained model uses hand landmark features extracted from the detected hand.
