# AI Rock Paper Scissors

An AI-powered Rock Paper Scissors game that uses real-time hand gesture recognition to let users play against the computer using a webcam.

The project combines computer vision, machine learning, and web technologies to detect Rock, Paper, and Scissors gestures and determine the winner of each round.

## Features

- Real-time webcam-based gameplay
- Hand gesture recognition
- Rock, Paper, and Scissors classification
- MediaPipe hand landmark detection
- Machine learning gesture prediction
- Computer-generated moves
- Win, Lose, and Draw detection
- Score tracking
- Interactive frontend interface
